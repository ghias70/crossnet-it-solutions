# Crossnet IT Solutions Website

## Run locally
Open `index.html` in a modern browser. Shop photos, product photos, icons, and brand wordmarks are local assets. Google Maps and Google Fonts need an internet connection.

## Brand colours
- Primary red: `#F23822`
- Bright red: `#FF4A2C`
- Main text: `#111C27`
- Muted text: `#596575`
- Borders: `#E6EAF0`
- Soft section: `#FFF7F5`
- Footer: `#111A22`

## Structure
- `index.html` — complete one-page site
- `style.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/images/shop/` — three supplied real shop photos
- `assets/images/products/` — generated local product photos
- `assets/icons/` — local SVG service/contact icons
- `assets/logos/` — recreated logo concept and brand wordmark tiles

## Notes
The logo SVG is a recreated concept based on the supplied shop sign, not the original official vector. Please confirm current opening hours and service availability before publishing.
